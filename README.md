This is a group project, being performed by Devin Marsh, Ronald Hamm, and John Wheeler, is created for Dr. Selvanayaki Kolandapalayam Shanmugam's CS175 (Web Design) class at Ashland Unviersity.

This project attempts to give a new and revised look to the Ashland University Bands in order to make it more appealing to newcomers and returners alike who may be interested in the Ashland University Bands program.

This project is being performed within the guidelines set by Dr. Shanmugam and syllabus given for the course.

This web-page project follows, to the best of its ability, the marketing guidelines set by Ashland University, including the use of logos, colors, fonts, and any other likeness guidelines set by Ashland University. 

This project is also being overseen by Director of Bands Professor Slade Presley Denman due to this project using the Ashland University Bands program as its base.
